ABSOLUTE OFFROAD - PROJECT DOCUMENTATION
================================================================================

PROJECT OVERVIEW
================================================================================
Absolute Offroad is a premium 4x4 accessories e-commerce platform specializing
in Toyota Land Cruiser, Hilux, and Ford Ranger upgrades. The site focuses on
curated product portfolios with guaranteed installation through an Approved
National Partner Network.

Built with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Framer Motion
for smooth animations and interactions.

================================================================================
DESIGN SYSTEM & STYLE GUIDE
================================================================================

COLOR PALETTE
--------------------------------------------------------------------------------
The design system is built around the Absolute Offroad brand identity with
vibrant, high-contrast colors that convey strength and premium quality.

Brand Colors:
- Brand Black: #000000 (Primary dark background, headers)
- Brand Yellow: #FFD700 (Accent color, CTAs, highlights)
- Brand Blue: #0066FF (Primary action color, links)
- Brand White: #FFFFFF (Text on dark backgrounds)

Primary Color Scale (Blue):
- 50-900: Full scale from lightest (#E6F2FF) to darkest (#001433)
- Default: #0066FF (Bright, energetic blue)

Accent Color Scale (Yellow/Gold):
- 50-900: Full scale from lightest (#FFF9E6) to darkest (#332B00)
- Default: #FFD700 (Premium gold/yellow)

Neutral Grays:
- Used for backgrounds (gray-50, gray-100)
- Text hierarchy (gray-600, gray-700, gray-900)
- Borders and dividers (gray-200, gray-300)

TYPOGRAPHY
--------------------------------------------------------------------------------
Primary Font: Inter (Google Fonts)
- Weights: 300, 400, 500, 600, 700, 800, 900
- Used for: Body text, navigation, UI elements
- Characteristics: Clean, modern, highly readable

Display Font: Bebas Neue / Impact
- Used for: Headlines, hero text, large displays
- Characteristics: Bold, impactful, attention-grabbing

Font Hierarchy:
- Hero Headlines: 4xl-7xl (text-4xl to text-7xl), font-black
- Section Headlines: 3xl-5xl (text-3xl to text-5xl), font-black
- Subheadings: xl-2xl (text-xl to text-2xl), font-bold
- Body Text: base-lg (text-base to text-lg), font-normal
- Small Text: xs-sm (text-xs to text-sm), font-semibold

Letter Spacing:
- Uppercase labels: tracking-[0.3em] (extra wide)
- Headlines: default tracking
- Body: default tracking

LAYOUT & SPACING
--------------------------------------------------------------------------------
Container System:
- Max width containers with mx-auto
- Responsive padding: px-4 (mobile) to px-8 (desktop)
- Consistent section spacing: pt-32 pb-20 (accounts for fixed header)

Grid System:
- Responsive grids: grid-cols-1 (mobile) → md:grid-cols-2 → lg:grid-cols-3/4
- Gap spacing: gap-6 to gap-8 (24px-32px)
- Card-based layouts with consistent padding

Spacing Scale:
- Small: 2-4 (8px-16px)
- Medium: 6-8 (24px-32px)
- Large: 12-16 (48px-64px)
- Extra Large: 20+ (80px+)

VISUAL STYLE & LOOK & FEEL
================================================================================

OVERALL AESTHETIC
--------------------------------------------------------------------------------
The design embodies a premium, rugged, yet sophisticated aesthetic that appeals
to serious 4x4 enthusiasts and fleet managers. The visual language balances:

1. Premium Quality: High-end product photography, clean layouts, sophisticated
   typography
2. Rugged Durability: Bold colors, strong contrasts, industrial-inspired
   elements
3. Technical Authority: Detailed specifications, fitment data, build guides
4. South African Context: ZAR pricing, local vehicle focus, regional imagery

DESIGN PRINCIPLES
--------------------------------------------------------------------------------
1. Clarity First: Information hierarchy is clear, products are easy to find
2. Mobile-First: Responsive design that works on all devices
3. Performance: Fast loading, optimized images, smooth animations
4. Trust Signals: Stock status, fitment data, partner network emphasis
5. Conversion Focus: Clear CTAs, easy navigation, prominent pricing

COMPONENT STYLE PATTERNS
--------------------------------------------------------------------------------
Cards & Containers:
- Rounded corners: rounded-2xl to rounded-3xl (16px-24px)
- Subtle borders: border border-gray-200
- Shadow system: shadow-sm (hover) → shadow-xl (active)
- White backgrounds on gray-50 base
- Hover effects: shadow-xl, scale transforms, color transitions

Buttons & CTAs:
- Primary: bg-accent-400 (yellow) with text-gray-900, font-black
- Secondary: bg-gray-900 with text-white
- Hover states: transform hover:-translate-y-1, shadow-lg
- Rounded: rounded-xl (12px)
- Padding: px-8 py-4 (32px horizontal, 16px vertical)

Badges & Labels:
- Uppercase, bold, wide tracking
- Rounded-full (pill shape)
- Accent colors (yellow-400) on dark backgrounds
- Small text: text-xs to text-sm

Images:
- Aspect ratios: aspect-square for product images
- Object-fit: object-contain (products) or object-cover (hero)
- Hover effects: scale transforms, smooth transitions
- Lazy loading with Next.js Image optimization

ANIMATIONS & INTERACTIONS
--------------------------------------------------------------------------------
Library: Framer Motion
- Smooth page transitions
- Scroll-triggered animations
- Hover state animations
- Hero carousel transitions
- Mobile menu animations
- Stagger effects for grid items

Animation Principles:
- Subtle and purposeful (not distracting)
- Performance-optimized (GPU-accelerated)
- Respects user preferences (reduced motion)
- Enhances UX without overwhelming

HEADER DESIGN
--------------------------------------------------------------------------------
- Fixed position at top (z-50)
- Dark gradient background: from-brand-black/95 to-brand-black/85
- Backdrop blur effect for modern glass-morphism
- Compact height with utility bar above
- Responsive: Desktop navigation + Mobile hamburger menu
- Logo adapts based on selected vehicle
- Search icon with global search functionality
- Scroll detection: Adds shadow when scrolled

FOOTER DESIGN
--------------------------------------------------------------------------------
- Dark background (brand-black)
- Multi-column layout: Shop, Support, Resources, Company
- Social media links
- Newsletter signup
- Legal links (Privacy, Terms, Cookies)
- Responsive grid layout

ROOT PAGES
--------------------------------------------------------------------------------

1. HOME PAGE (/)
   File: app/page.tsx
   Description: Main landing page featuring hero carousel, brand showcase,
   product categories, featured products, build gallery, and newsletter signup.
   Key Sections:
   - Hero Section: Rotating carousel with 3 main build concepts

PRODUCT PAGES
--------------------------------------------------------------------------------

2. PRODUCTS CATALOG (/products)
   File: app/products/page.tsx
   Description: Main product listing page with category filtering. Displays
   all products in a responsive grid with filtering by category (Suspension,
   Armour, Interior, Recovery). Shows product images, prices, stock status,
   and category badges.
   Features:
   - Category filter buttons
   - Product grid (1-4 columns responsive)
   - Price display with sale price support
   - Stock status indicators
   - Product badges (New, Sale, etc.)
   - Search params for category filtering

3. PRODUCT DETAIL PAGE (/products/[slug])
   File: app/products/[slug]/page.tsx
   Description: Individual product detail page with comprehensive information.
   Features full product specifications, fitment data, related products, and
   detailed descriptions.
   Key Sections:
   - Product image gallery
   - Product name, brand, category
   - Price (with sale price support)
   - Stock status
   - SKU display
   - Add to Cart button
   - Vehicle fitment information
   - Full description
   - Key features list
   - Specifications table
   - Related products from same brand
   - Breadcrumb navigation
   Features:
   - Static generation with generateStaticParams
   - ZAR currency formatting
   - Responsive 2-column layout (image + info)
   - Related products recommendations
